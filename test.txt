4｜P0｜`app/routers/pos.py:66-73`、`232-235`（根因 `app/models.py:24`）

原因：`AutoPart.oem` 只有普通索引不是唯一键，同一 OEM 多品牌时 `UPDATE ... WHERE oem=?` 会一次改动所有品牌行，扣/退库存都作用到错误商品，`rowcount==0` 也无法再作为“库存不足”的判据。

修复：

```python
part = session.exec(
    select(AutoPart).where(AutoPart.oem == item.oem, AutoPart.brand == item.brand)
).first()
result = session.exec(
    update(AutoPart)
    .where(AutoPart.id == part.id, AutoPart.stock >= item.quantity)
    .values(stock=AutoPart.stock - item.quantity)
)
if result.rowcount != 1:
    raise HTTPException(status_code=400, detail="库存不足或商品已变更")
```

同时给 `(oem, brand)` 加唯一索引，并让 `OrderItem` 存 `part_id` 供退款精确回补。
